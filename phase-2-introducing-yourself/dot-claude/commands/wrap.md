Wrap up this session:

1. Summarize what changed: files, decisions, project state.
2. Route each item to its home (see ~/claude-context/workflows/_index.md and the
   routing table in the setup guide):
   - durable fact or preference  -> memory/core.md
   - dated decision or ruling    -> memory/decisions.md
   - a person                    -> memory/people.md
   - project narrative           -> projects/<name>/context.md
   - structured tasks            -> my tracker (not a file here)
3. Leave anything you are unsure how to file in inbox/ with a one-line note.
4. Do not invent facts. Ask me to confirm anything ambiguous before writing.
