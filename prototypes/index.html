Home page

Three directions

All three are one self-contained file: HTML, CSS, and no JavaScript beyond the light/dark toggle. Each has that toggle top right, because the atmosphere had to work in both and it is the fastest way to check. Open them full screen.

The imagery is generated in the browser rather than fetched: layered gradient fields with an SVG turbulence filter over them for the structure real fog has and a plain blur does not. It costs nothing to load, scales to any screen, and shifts with the theme. Each file has one hook, --photo, that swaps in a real image the moment there is one to swap in.
